工具与使用方式

顶部可打开配置引导、录音设置、语音工具、同传工作台和悬浮转录。声音面板有六个操作入口：语音文件、模型配置、时间轴人名、声音合成、输出音频和情绪分析。按当前任务选择即可。

本地模型需要完整模型包、相应原生组件和足够内存。服务模型需要正在运行的服务与匹配协议。云端 API 需要账户和能力权限。可先使用一种方式，不必一次配置全部服务。

开始使用前

本手册适用于 0.5.0 桌面版。先检查模型文件和服务连接，再用自己的设备试录、翻译和试音。标注「实验」或不可用的功能请按界面提示操作；模型、语言和设备不同，识别效果与同传延迟也会不同。

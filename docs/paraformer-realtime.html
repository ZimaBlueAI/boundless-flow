阿里云 Paraformer 实时转写

边讲话边显示文字，停顿后由服务端确认句子。使用已保存的阿里云连接，不必在录音设置重复填写密钥。

先保存连接，再开始录音

先在配置引导保存 Aliyun 连接和识别模型，再到录音页面选择服务。更换模型仍回配置引导保存，无需在多个页面重复填写密钥。首次使用请用自己的账号和录音设备录一小段，确认权限、识别效果与费用；速度和质量取决于服务、网络及录音条件。

开始前准备

  • 阿里云百炼 / Model Studio 的有效账号、北京地域可用的服务和对应 API Key。服务可能收费，以账号的开通情况和官方账单为准。
  • 可正常录音的输入设备和网络。音频会持续发送到所选阿里云服务；此路径不需要下载本地 ASR 模型。

第一次使用：按顺序设置

① 配置引导 · API② 保存 Aliyun③ 录音设置 · 实时 API④ 讲话 · 停止 · 等待收尾
  1. 打开「配置引导」→「API 配置」。 找到「阿里云 Aliyun」，启用连接。已经保存过阿里云连接时，可以复用它，不需要额外创建一份密钥。
  2. 保存北京域名和 API Key。 可沿用默认地址 https://dashscope.aliyuncs.com/compatible-mode/v1 ，或填写实际北京工作区根地址 https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com。工作区 ID 要换成自己的实际值。本次接入仅支持这两类北京服务地址，不能用新加坡地域或第三方域名替代。
  3. ASR 模型填 paraformer-realtime-v2。 完成引导并保存。不要把录音文件转写模型、TTS 或语音对话模型填到这里。
  4. 打开「录音设置」。 「录音识别方式」选「实时 API」，「已保存的服务」选「Aliyun · Paraformer」。页面复用已保存的地址与密钥；已在配置引导保存的 ASR 模型仅供查看，不在录音页面重复填写模型或 Key。
  5. 确认语言，再录一小段。 可填写 zh（中文）、en（英语）、ja、yue、ko、de、fr、ru，或留空自动识别。明确指定的源语言会保留为本次录音的语言约束；语言提示不保证识别永远正确。回到实时字幕，点击「开始」，用正常音量说一句话并稍作停顿。
  6. 点击「停止」后等待收尾。 停止采集后仍需等待服务端返回最后的结果和 task-finished，之后再结束本次转写。不要把临时文字当作已确认的最终记录。

修改连接或模型：从「管理服务」进入

  1. 在「录音设置」的实时 API 区域点击「管理服务」，直接打开「配置引导」的「API 配置」步骤。
  2. 找到「阿里云 Aliyun」，核对北京服务地址、API Key 与 ASR 模型。实时识别模型应为 paraformer-realtime-v2；修改后完成引导并保存。
  3. 返回「录音设置」，选择 Aliyun · Paraformer，核对显示的模型，再开始新的录音。保存的更新用于下一次录音，当前录音不会中途切换模型或服务。

如果提示「模型配置已更新」，请刷新设置或重新选择服务。若保存成文件转写、TTS 或其他不支持的模型，请点击「管理服务」纠正并保存；程序会提示修正，不会私自换用另一种模型。

看到什么，才算完成

边说边显示临时文字可以被后续结果修正。
服务端确认约 400 ms 的停顿作为服务端分句阈值；不是 400 ms 出字幕的保证。
停止与收尾还要等待 task-finished；已有一句最终文字不等于整个录音结束。

停止采集后的确认尾句仍会补入字幕和会议记录；已启用翻译时，也会提交该句继续处理。停止后不再向其他窗口输入文字。请等本次任务完成后再开始下一次录音；未确认的草稿不会作为终稿补入。

遇到问题时怎么做

看不到 Aliyun · Paraformer
先确认使用的是包含实时转写功能的 r466 或后续版本；本页的统一模型管理操作对应 r468 候选版。再回配置引导确认 Aliyun 已启用、模型名正确，并且已完成保存。
模型框不能编辑，或提示模型不支持
这是配置引导中已保存的 ASR 模型。点击「管理服务」，将模型改为 paraformer-realtime-v2，完成保存后返回并重新选择服务。文件转写模型不能代替实时识别模型。
地址、密钥或权限不匹配
检查北京地域、工作区与 Key 是否对应，确认账号已开通服务。密钥只在配置引导修改，不要在其他页面重复复制或向第三方域名发送。
中途断网、失败或停止后没有最终句
已确认结果和原始录音保留，未确认草稿不会被改成最终记录。程序不会自动重连或重发音频。先核对错误和网络；需要补转写时，手动使用保存的录音走文件转写流程，另行确认所选服务与可能费用。

这项功能的范围

这是实时语音转文字入口，不是录音文件上传转写、声音克隆或完整同声传译。译文、译声与灵录报告仍分别使用各自的功能与配置，不能仅凭接通 Paraformer 就视为全部完成。

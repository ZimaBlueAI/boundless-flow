灵录 / 亲子对话

芽记 · 亲子成长观察

把已保存的亲子对话整理成可阅读、可核对、可分享的报告。

准备录音配置模型阅读与核对保存与导出遇到问题

截图来自当前软件界面。录音和报告内容为验证用的示例，不代表真实家庭的情况。请使用自己的录音与可用模型。

1. 先保存录音和转写

还没有保存的对话时，先按录音变文字教程完成转写并保存。也可以导入已有录音，完成音频转写后再使用芽记。

先听原音，校对文字和说话人标签。报告中的引语、时间和说话人来自保存的转写。误听的字会直接影响后面的观察，模型不能替你确认谁说了这句话。

进入会议区域，展开灵录，点击「芽记报告」。在「选择已保存录音」中选中这次对话。打开面板和载入旧报告都不会调用模型。

2. 选一个可用的报告模型

展开「报告模型设置」。已有共享纪要配置时，点击「读取共享纪要设置」。这里会复制服务、模型 ID、地址和密钥；后续修改只用于当前报告，共享配置保持原值。

也可以在这里填写自己的配置。本地服务需要先运行并加载文字模型。云端服务需要填写实际可用的模型 ID 和 API Key。此功能整理转写文本，不会自动下载或启动文字模型。

点击「生成芽记」后，完整转写会分批发送到所选服务。长对话可能需要多次调用。想全程在本机处理时，请确认所填地址指向本机运行的服务。

可选服务包括 Ollama、OpenAI 兼容接口、DeepSeek、Kimi、MiniMax、火山方舟、智谱、OpenAI、Anthropic、Gemini，以及 vLLM、MLX、SGLang 和 LlamaEdge。可用模型与账户权限由所选服务决定。

3. 读报告，也回到原话看看

每章先整理对话里的事情和简短故事，再写出值得保留的「种子」。有明确依据时，会呈现可能的 AHA 瞬间。金句直接摘录原话，方便回顾。

哲学、历史、科学、心理和德育视角提供讨论问题。原文依据不足的视角会显示暂不解读。报告不会自动搜索外部研究或历史材料，这些视角需要结合上下文判断。

点击解释旁边的引用编号，可以跳到完整转写中的对应片段。核对说话人和时间，再听原音。引用检查只能确认引语确实存在，不能保证模型的解释正确。

4. 保存、停止和分享

生成完成后，报告与生成时的转写快照会保存在该录音的报告目录。再次打开并选中这段录音，可以载入已有报告，无需重新调用模型。

生成中可以点击「停止生成」。关闭本次生成的窗口也会请求停止；打开其他窗口中的已有任务查看进度后，关闭查看窗口不会自动停止那个任务。进入保存阶段后，停止按钮会禁用。

点击「导出报告」，选择一个正常工作目录，保存为 HTML。图片、样式和来源转写包含在单个文件中，可离线打开。用浏览器打印也能保存成 PDF。

原文或说话人后来改动时，已保存报告仍保留生成时的快照。面板会提示原文已更新。想得到新报告，请确认当前转写后重新生成；旧报告不会被直接覆盖。

遇到问题时从这里检查

  • 没有录音可选，先完成并保存一段转写，再点「刷新录音」。
  • 生成按钮不能点击，检查是否选了录音，以及服务地址和模型 ID 是否已填写。
  • 引语与原文不符或格式无效，本次结果不会发布。旧报告保留，可以重试或更换模型。
  • 生成时原文发生变化，请载入当前录音，校对后重新生成。
  • 任务状态暂未确认，先点「连接已有任务」。确认任务状态后再决定是否继续，避免重复调用。
  • 一个片段过长或整场对话超过处理上限，请先分段或分场保存。软件会提示，完整原文不会被悄悄截断。

配置引导

首次使用按五步配置。使用中补齐缺项，可保存后返回原任务，继续编辑草稿。

图中为软件实际界面，配置和会话使用示例内容。请按你自己的模型、服务和录音填写。部分配置图为较早界面；新版 VoxCPM2 Runtime 在模型库登记时配置，声音面板与同传直接选择已配置模型或服务。

使用中补配置，保存后回到原任务

声音工具、同传工作台和音频转写中的配置入口，会直接打开所需步骤。上方显示正在为哪个任务补齐配置，下方提供保存并返回，不必重新走完五步。

  1. 保留当前文字、台词、参考原文或待导入音频，点击该任务的配置入口。
  2. 只补齐需要的模型或服务，点保存并返回。界面不刷新，回到原工作区或面板；新配置会应用到当前界面。
  3. 不想保存这次配置，可点不保存返回或关闭、按 Esc。原任务草稿保留，本次未保存的配置修改放弃。
  4. 返回后检查模型、参考音与语言，再主动开始。返回动作不会自动录音、生成、上传或下载模型。

保存失败时，配置表单保留供重试。如果提示「配置已保存，应用或返回尚未完成」，点重试返回；不会重复保存。音频导入的文件路径、转写方式和语言也会保留。首次启动的完整配置仍在最后一步点「完成并保存」。

1 · 系统麦克风

选择你实际讲话使用的输入设备，确认系统麦克风权限与输入电平。远程会议声音和自己的麦克风可能是不同设备；能听见对方不代表录音输入已包含对方。用短录音验证输入后，再开始正式会议。

2 · 快捷键

默认 RightAlt 用于开始／停止录音，也可在此更改。先在主界面试按，再到悬浮转录试按同一快捷键。没有响应时，确认软件正在运行，检查其他软件或输入法是否占用了该键；只保留一个应用实例。

3 · 模型与参数

本地模型只登记一次，各功能按名称选择。先准备好模型文件，再打开「配置引导页 → 本地模型库」。在这里统一保存用途、家族、名称、模型路径和大小／量化规格。

  1. 选用途与家族。识别用「语音识别」，克隆／设计用「语音合成」；翻译、声纹和情绪各选对应用途。
  2. 写清名称与规格。例如「Qwen Base · 0.6B」与「Qwen VoiceDesign · 1.7B」分别登记；大小／量化栏可填 FP16、Q4_K_M 等实际规格。
  3. 浏览并登记。目录模型勾选「选择文件夹」；单个 ONNX／GGUF 文件取消勾选。选自己的保存位置，点「登记模型」，继续完成引导并保存。

登记后，在库上方「转录使用的模型」选择名称，点击「检查模型」，再展开「试转录一段录音」。需要下载时，点击当前家族旁的「下载准备」，或展开库后方的「下载模型与组件」；先核对来源和目标磁盘，再明确开始下载。登记只加入当前草稿，最后请完成并保存配置。

同族不同大小或量化分别登记。图中的 FP16 与 Q4_K_M 仅展示登记方式；只有匹配软件后端的完整模型包才能运行，填写量化名称不会转换模型。登记 VoxCPM2 时，若需要独立运行组件，在同一条目填写「VoxCPM2 Runtime 目录（可选）」。该目录随模型保存；声音面板和同传选择此条目后自动使用，无需再次填写。留空使用默认运行组件，不会开始下载。

在功能页选择，不再重填路径

打开声音面板的「模型配置 → 本机模型」，从「已登记的声音模型」选择所需名称。实时转录、同传、声纹、情绪和本地翻译也从各自的已登记列表选择；同传可选与主转录不同的识别模型。

需要新增或修改时，点功能页的「管理本地模型」返回模型库。编辑后完成引导保存，再回到功能页选用；关闭未保存引导会放弃修改。

检查与准备

「检查文件」只检查文件是否匹配。克隆还需选择参考录音，点「检查模型」，再生成短句试听；换参考录音后重新检查。

提示需要转换时，点「准备原生模型」。完成后会新增并选用带 Native 的条目，原模型条目和原目录保留。Index 的新增包在所选目录的 .boundless-flow/native 中，不转存 C 盘；准备仍需该磁盘有写入权限和剩余空间。「移除登记」不会删除模型文件。

4 · API 配置

可搜索服务名称或能力，展开需要的卡片，填写 Base URL、API Key 和实际可用的单个模型 ID。填写示例模型名不会安装模型。翻译还需在「翻译服务」选择已配置的服务，并点「开始翻译测试」检查短文本。完成引导保存后，同传工作台从「翻译服务」直接选用已配置连接，不再重复填写地址、密钥和模型。

试译面板显示当前的「源语言 → 目标语言」，源语言沿用「模型与语言」中的设置。修改语言后请重新试译；默认例句可随已知源语言调整，你编辑过的原文会保留，请确认其语言与设置相符。试译返回的文字明显不符合目标语言时，结果不会采用，也不会自动重试；核对设置和原文后再手动试译。语言检查不能替代人工复核。

保存配置不等于接口通过测试。LLM、ASR、TTS、实时能力的鉴权和协议可能不同；普通聊天兼容 URL 不一定能用于语音或双向流。流式语音在本引导的配置与试音区域选择适配器、保存连接并试音；克隆模型服务在「模型与参数」中配置服务根地址和密钥。使用时选择已配置的服务，语言、参考音、音色、情绪和播放方式仍可按当前任务调整。

按这次任务检查配置

在配置引导最后一步，从这次准备做什么选择任务，再点检查当前配置。默认的「录音与字幕」只检查应用、输入设备和识别模型，不要求配置声音克隆或纪要文字模型。

  1. 要做其他功能时，选择「灵录纪要」「本机声音克隆」或「分段同传」。同传按当前实际优先级检查译声：模型服务、语音 API、本机原生模型或兼容合成。
  2. 有缺项时，点结果下方的下一步，直接进入对应配置步骤；沿用已有模型库，不需要在第二处填写模型路径。
  3. 基础检查通过后，点下一步：试转录或对应试音入口。按钮只打开试用区域，不会自动录音或调用服务。
  4. 「查看全部保存项」默认收起，需要时展开核对。首次配置最后点完成并保存；使用中补齐可点保存并返回。关闭时放弃本次未保存的配置修改，原任务草稿保留。

找到文件、填好 API 参数不等于识别质量、麦克风权限或服务额度已经确认，仍需短样本试用。实际生成纪要、翻译时会把文字发送至所选服务；模型服务译声还会接收参考音。任务下方会说明适用范围。

修改配置后请重新检查。「复制脱敏摘要」不包含密钥、地址、路径和试运行内容。局域网中的 Ollama 纪要服务可以不填密钥。

5 · 使用说明与保存

首次配置在最后一步统一保存；使用中补齐配置可直接点「保存并返回」。重新打开引导时以已保存配置为基础。模型选择与不同服务的草稿各自保留在当前引导流程中；关闭未保存引导会放弃这些修改。

「配置备份与恢复」用于查看候选并明确恢复；先确认来源与范围。损坏配置不会被当作成功读取，恢复前保留现有文件。

配置一次，在各工作台直接选择

在配置引导页登记本地模型，填写容易认出的名称，并在规格中注明大小或量化。不同规格分别登记；VoxCPM 的 Runtime 目录随模型一起保存。

使用页面显示模型的用途、名称和已登记规格。旧配置若只叫 ONNX 这类后端名，会显示目录名帮助区分；显示名称不代表文件或能力已验证，先检查模型，再做短样本试用。

同传的「语音识别模型」负责把输入变为文字；「分段译声模型」用于 Mini 录音结束后的合成；「持续克隆译声模型」结合参考录音为译文分段发声。按使用方式选择对应模型即可；「管理模型」进入配置引导页，不需要在工作台重复填写路径。

支持的连续参数可以转动表盘，或聚焦后用方向键调整，也可以直接输入数字。运行时不可调整的控件会变暗，不能修改正在使用的模型。

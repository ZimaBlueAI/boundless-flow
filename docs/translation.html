选择翻译服务

  1. 打开配置引导的 API 配置，搜索并配置所需翻译或 LLM 服务。使用服务器实际提供的模型 ID。
  2. 在「翻译服务」明确选择该服务，填写测试原文与目标语言，点击翻译测试。此测试不会自动保存引导或创建会议。
  3. 完成引导保存后，在录音／同传设置启用翻译，选择主目标语言和额外字幕语言。

HY-MT2

支持兼容 API 与已下载本地模型文件的托管服务方式。打开 HY-MT2 卡片，在本地运行区选择配套服务组件与完整 GGUF 文件，再选择「计算设备」。使用 NVIDIA GPU 时，可留空「CUDA 组件」自动查找；找不到时，选择配套的 ggml-cuda.dll。组件和驱动须匹配，设备检查失败时可改用 CPU。启动后试译一段短文本，再点击「用于翻译」并完成配置保存。

Index-Translate 本地运行区使用同样的设备选择。已保存配置恢复时会重新校验 CUDA 组件；替换组件后需重新启动并选择「用于翻译」。原始训练权重目录与 GGUF 服务包是不同输入，不能只改文件后缀。首次加载与首次推理可能较慢，开始正式同传前先完成短文本测试。

Index-Translate

在 Index-Translate 卡片选择公共接口或自己的本地兼容服务，也可使用已下载文件启动托管本地服务。公共接口、模型名称和限额由服务方决定；以当前卡片和实际响应为准。不要将保存成功视为公共服务可用。

字幕与恢复

中文原声，英文字幕

  1. 录音源语言选「中文 / zh」，翻译目标语言选「英语 / en」。源语言决定识别，目标语言决定译文；不要把识别语言也设为英语。
  2. 先看原文是否忠实于录音。原文识别错误时检查麦克风、识别模型和源语言设置；翻译不能保证修复识别错误。
  3. 需要固定专业词、人名或产品名时，填写对应目标语言的术语表。翻译结合有限上文消歧，但只翻译当前片段。
  4. 译文应保留否定、数字、条件和疑问。完整句可先翻译；尚未说完的价格、数字或条件可能暂缓，等待后续内容补齐，不应凭猜测补出结论。录音片段结束时，会继续处理保留的末尾内容。

短句暂时没有译文时，先看原文是否已出现、录音是否仍在继续，再等待后续讲话或片段收尾。字幕更新会兼顾实时性与原意完整，尽量避免把一句话的意思拆散。

配置引导中的文字试译会显示当前「源语言 → 目标语言」；源语言沿用「模型与语言」的设置，原文应使用相应语言。换语言后重新试译；自己编辑的原文会保留。若试译返回的文字明显不符合目标语言，本次结果不会采用，也不自动重试，请核对设置后手动再试。此检查不能判断所有语言或语义错误。

正常翻译直接显示，不另等一轮校对。明显不符合目标文字系统的结果会尝试一次校正，可能增加该段延时和云端请求费用；仍失败时可查看「翻译恢复」。这种检查不能保证识别所有语言错误或语义错误。

当前 ONNX／FunASR 实时管线最多三路译文，共用翻译 API，每种语言单独请求；主语言用于语音播放、悬浮字幕与输入，修改在下次录音生效。额外语言会增加请求与耗时；先确认一种语言正常，再增加语言。

若某段失败，打开「翻译恢复」查看记录并明确重试。重试云端请求可能再次计费，翻译和录音可分别检查。会议导出可选择已保存目标语言；导出不会重新翻译缺失段落，需先在恢复工作流补齐。

先试录，再开始

第一次使用，先确认软件能录到你的声音并正确显示原文，再开启翻译或语音播放。下方各章介绍配置、字幕、会议、音色与同传的操作；截图中的编号对应图下说明，点击图片可放大查看。

  1. 打开「配置引导页」，选择麦克风和识别模型；先只测试转录。
  2. 录制一小段讲话，停止后检查原文和会议记录。
  3. 单独配置并测试翻译、语音合成，然后再组合为同传。

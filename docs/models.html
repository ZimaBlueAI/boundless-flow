01

先完成一次短测试

中文转录可先用 SenseVoice。本地克隆可选已准备的 Index、Qwen Base 或 VoxCPM2；文字设计音色选 Qwen VoiceDesign。先确认一种目标语言正常，再在同传工作台组合识别、翻译与译声。

查看配置引导教程 →
  1. 1在配置引导登记模型或 API
  2. 2用短录音、短文本检查识别或生成
  3. 3保存后，在对应工作台选择已配置记录
本地模型：选择 CPU 还是 NVIDIA GPU？

模型文件需另行准备。在配置引导检查所选模型的组件与设备，再选择 CPU 或 NVIDIA GPU；不同引擎的设备支持不同。检查通过后，先生成一段短语音。

Windows r469 的原生 CUDA 组件包含计算能力 7.5、8.0、8.6 和 8.9 的代码，并提供 PTX 前向兼容路径。已在 RTX 4090 完成 VoxCPM2 生成验证；其他显卡和模型仍需短句试音，不能据此推定全部兼容。软件会在加载模型前检查显卡、驱动与组件；检查未通过时，可在配置引导改用 CPU。FireRed 当前使用 CPU。

Windows 本机可用 NSIS 安装包，或当前 r475 本地测试签名 MSIX。旧 r468/r469 未签名预览包不能直接安装；本地 MSIX 测试需先明确导入并信任与包匹配的公开 CER，不表示已获 Microsoft Store 认证。查看本地 MSIX 安装步骤 →查看安装与首次配置说明 →

配置与使用边界
一次配置
配置引导 → API 保存 openspeech.bytedance.com、语音控制台 Key 和已开通的 volc.seedasr.sauc.duration / volc.seedasr.sauc.concurrent 资源；录音设置选实时 API → Doubao，复用已保存凭据。
语言与收尾
源语言须自动，提示留空；不支持强制语言。服务端自动分段，停止仍等待确认。断线保留原音，不自动重试或重发，不将草稿补成最终结果。
可用版本
r468 候选版包含此功能；模型在配置引导保存，使用页选择服务，更换时点击「管理服务」。账号权限、计费、实际识别、实体设备与性能仍需验收；不是完整同传或克隆，不承诺固定延时。

服务接入

Aliyun · Paraformer

持续发送语音，接收临时文字与服务端确认句。

配置与使用边界
配置入口
配置引导 → API：保存北京域名、Key 和 paraformer-realtime-v2；录音设置选「实时 API」→「Aliyun · Paraformer」，复用凭据。
处理方式
16 kHz 单声道 PCM；服务端约 400 ms 停顿分句。停止后继续等待 task-finished；失败保留原音，不自动重连或重发。
版本与验收
r466 预览版已包含实时转写；r468 候选版支持统一管理模型，使用页选择已保存的服务。协议与本地模拟连接已检验，付费账号与实体麦克风尚未验收。不是文件转写、克隆或完整同传。

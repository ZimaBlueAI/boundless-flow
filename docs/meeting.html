安排你的会议工作区

  1. 在「AI 会议视图」找到卡片标题旁的六点把手，按住并拖到需要的位置；插入线显示放开后的落点。
  2. 不想拖动时，点击把手，在位置菜单中选择区域或调整顺序。也可以聚焦把手后使用方向键移动。
  3. 点击卡片标题折叠或展开。实时转录内容较长时，在卡片内部滚动浏览。
  4. 调整后的布局会保存在当前设备。需要重新开始时，点击会议视图的「恢复默认布局」。

移动和折叠保留正在编辑的内容。布局记忆仅保存卡片位置，不代替会话保存或纪要保存。

浏览和修订会议

  1. 停止录音并等待收尾，在「会议与纪要」刷新列表，选择会话。录音中可以选择实时会话查看正在到达的段落。
  2. 通过时间轴、全文搜索、发言人及待复核筛选定位段落。长会议按页显示，搜索覆盖全部段落。
  3. 选择段落，复核原文、时间和发言人标记；修改后点击保存；翻页或搜索不会保存草稿。

实时文字纠错：有疑问时保留整段原文

适用版本：Windows r512 或后续安装预览。更早安装预览不含本节的会议纠错检查。下述行为用于已开启文字纠错、且支持这条处理流程的实时会议，不代表所有识别方式或报告入口都经过同一检查。

  1. 开始前先核对识别源语言，并按原有流程开启实时会议文字纠错。纠错模型返回后，软件会检查输出语言、数值、否定表达和已识别的事实线索，核对它们与该段识别原文是否一致。
  2. 响应后的检查有时间和文字容量边界。模型调用失败、超时、检查未通过或检查无法按时完成时，整段保留识别原文，并单独提示本次纠错没有采用。提示与会议正文分开，不会把报错当成会议内容。
  3. 点击停止录音后，已接收的段落仍会继续处理、排空和保存；请等待收尾状态结束。若任务被取消，之后到达的派生纠错稿不再发布，不用反复启动纠错去追赶旧请求。
  4. 阅读结果时，仍需对照原话和保存的原音，特别核对姓名、金额、日期、“不”“没”等否定词。原音可用时，可从段落时间回听；遇到疑问先保留原文，再人工修订。

这些检查只覆盖能识别到的线索，不能保证未知中文姓名正确，也不能保证完整语义都未改变。已经保存的旧报告不会自动改写。需要新报告时，先复核原文，再从相应报告入口重新生成；报告与纠错提示分别核对。

会议纠错：保护已经登记的姓名和术语

需要 Windows r513 或更高版本。r512 及更早安装预览不包含本节保护。它只用于支持实时文字纠错的会议流程，不代表所有识别方式或灵录报告入口都采用同一检查。

  1. 打开配置引导中的中央文字规则，在禁改词登记需要保留的姓名、品牌或术语，例如「周琪」。词典用「听到／写成」登记正确写法；批量导入可参考词典导入与历史。这里不用重新配置模型。
  2. 保存规则后，再开始一段新的会议录音。软件在这次录音开始时记住整场会议使用的规则。录音中途再修改设置，只对之后新开始的录音生效，不改变这次已接纳段落的规则。
  3. 按原有流程启用实时文字纠错。模型返回后，软件会核对原文中已经出现的登记名称，及它们与否定、数值和已识别事实的关系；不是只比较“字数差不多”。姓名改字、名称调换或把“不”挪给另一人时，不采用这份纠错稿。
  4. 词典中所有“写成”的目标词都会作为只保护的锚点，包括聊天、邮件、代码等其他用途的目标词。这里不自动替换原文、不套用用途模板，也不把词表作为额外提示发送给模型。若已启用云端文字纠错，当前段正文仍沿用原服务发送方式，正文中的姓名仍属于正文。
  5. 规则无效、模型失败、检查不通过或超时，整段保留识别原文，并单独提示原因；明确取消后不发布晚到的派生纠错稿。先核对原话和可用原音，再人工修订，不反复启动旧请求。
原文与模型变化你会看到什么
「周琪整理会以记录」→「周琪整理会议记录」名称和事实关系保留，明确的小错字或标点修正仍可通过。
「周琪」被改成「周琦」不采用这份纠错稿，保留原文并提示。
「周琪不签字，王悦签字」被改成「周琪签字，王悦不签字」不采用否定关系调换后的文字，保留整段原文。

会议不会根据你当前浏览的项目猜测录音归属或自动套用项目词典。项目词典仍用于已保存项目的主动文字整理。未知姓名，以及原始识别已经写错的姓名，不能承诺自动纠正。这也不是完整语义等价证明；重要姓名、金额和否定词仍须回听核对。

本节不开放增强声音输入的自动投递，不改变声纹门槛，也不代表声音身份或真实中文质量已通过验收。

生成并整理纪要

重复发言请分别回听对应时间，不要仅按文字相同认定为重复记录。临时识别文字还会修订，生成纪要前先等待片段确认。

先复核原文，再选择会议纪要的 LLM／灵录配置并生成。纪要可包含摘要、章节、决策和行动项；核对负责人、截止日期、数字与原文依据后保存。模型没有生成的内容不要凭空补作会议决定。

实时纪要归档或最终纪要写入失败时，查看错误并明确重试；已有会话不因单次失败自动丢弃。生成和导出是两个操作。

导出原文、字幕与纪要

展开会议导出区域，按实际按钮选择 TXT、JSON、HTML、SRT／VTT 输出及已保存语言。字幕导出保留段落时间；导出前复核翻译和说话人。纪要使用自己的导出入口；灵录主题报告在灵录区域预览／导出。

列表中有异常会话

某个会话的元数据损坏或不可读时，列表会标记该条异常，其他有效会话仍可浏览。先查看可用原文；这不表示损坏元数据已被修复。整个会话根目录无权限等错误会明确显示，修复路径后再刷新。

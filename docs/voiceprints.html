声纹与情绪

登记、录音复核、独立样本比对与校准；相似度不是身份概率。

登记声纹

  1. 打开「声纹识别」，输入显示名称，选择配套的声纹模型。更换模型后，旧档案可能不再兼容，需在新模型下重新提取。
  2. 添加同一人的 1–8 段独立参考录音：单声道 16 kHz WAV，每段 1–60 秒。选择后检查录音，移除损坏、无变化或重复文件。
  3. 先试听确认，再创建档案。可重命名、归档、恢复，复核参考音选择并保留历史版本。新档案在校准前不用于自动身份匹配。

检查讲话区间

可选 Silero VAD 或 MarbleNet VAD 检测讲话区间。电平检查只测量信号，不证明存在人声或只有一位说话人；VAD 提示也不自动裁剪或拒绝录音。选择候选讲话区间后先试听，明确采用才用于本次登记／比对；可撤销回原录音。

比对与验证

选择另一段独立录音作为探测音，比较同模型、同运行版本的兼容档案。查看候选分数、前两名分差与排除档案。分数接近、未校准或没有兼容档案时，以界面提示为准，不把第一名直接当作已确认身份。

用独立测试材料进行验证／评估，不把登记录音当测试集。复核误接受、误拒绝、未知人和实际麦克风条件；更换模型、参考或条件后重新检查校准与评估适用范围。

先看报告中的样本来源

在「声纹质量评测」中点击「打开评测报告」。先看「样本来源 · 报告声明」卡片，再阅读正确识别率、未知人误认率等数据。来源由报告提供者声明，打开报告不会验证录音里的人是谁。

  • 合成样例：用于检查功能，不能作为真人识别质量的依据。
  • 扰动或转码测试：用于观察噪声、转码等条件下的稳健性，不能替代独立真人录音的评测。
  • 原始真人录音：表示报告声明使用真人录音；人物身份、采集条件与样本独立性仍需核实。

「设备跨数据集隔离」的「已声明」只表示校准集与测试集使用不同的设备标签；不代表已验证同一个人换麦克风后仍能正确识别，也不是质量认证。「未隔离」表示未按设备分开这两个集合。

旧报告缺少来源或设备资料时，相应项目显示「未提供」。这表示资料未知，并不等于真人录音或设备已隔离。需要据此判断模型质量时，请先向报告提供者确认资料；仅打开报告不会改变当前模型或身份阈值。

先试认所选声音，再检查输入准备

本节试认步骤需 Windows r512 或后续安装预览。试认不代表真实声纹质量或自动输入已通过验收。

在「配置引导 → 本地模型库」登记、选择声纹特征模型和说话人分离模型，保存配置。它们与可选的讲话区间检测模型不同。试认沿用已保存的配置，这里不用再填写模型路径。

在声纹库中选中一个未归档档案；在「比对一段新录音」中选择一段独立的 1–60 秒录音，完成音频准备和录音检查。不要重复使用登记录音。点击「试认所选声音」。

试认检查整段已准备录音，独立于上方选择的讲话区间裁剪。它与实际声音输入共用检查：单人语音覆盖、整句、窗口和语音区间。遇到拒绝即停止，未检查的区间不计为通过。

展开区间明细，可查看是语音覆盖不足、多人讲话、相似度低于门槛，还是候选分差不足。相似度偏低不代表一定是其他人；本次通过也不是身份认证或准确率结论。

处理中可取消，不采用取消后的结果。换录音、切换或更新档案、修改已登记模型会使旧结果失效。档案与模型不一致时，可在该档案使用「用当前模型重新提取」；缺模型时回配置引导检查。

试认不输入文字、不改门槛；指定声音自动输入仍未开放。试认成功不等于身份认证，也不表示已通过跨应用输入验收。Windows r514 或更新版本加强了切换输入框和停止录音时的保护，但不开放此入口、不降低声纹门槛；停止后的操作见录音收尾与保存检查。若本人的独立录音仍失败，先改善登记录音再试。

核验报告原音

在声纹工作台展开评估报告，打开验证报告。仅打开报告会重新计算统计，不读取录音；需要你明确点击「选择录音清单并核验」，再选择 JSON 清单。

  1. 清单使用 schema_version: 1 和 audio_files 数组；每条包含 sample（报告 input.manifest.samples 中的准确 id）与 path。须包含全部来源样本，不能遗漏、重复或增加未知 ID。
  2. 路径可使用绝对路径，或位于清单目录内的相对路径。WAV 须为单声道 16 kHz、1–60 秒；核验不会转换、补静音、上传或修改原音。
  3. 查看已检查／一致／总数与异常列表；缺失、损坏、哈希不同和时长不同均会显示对应样本和文件。可取消，已完成的上次结果会单独标注保留。

核验结果适用范围

若提示报告已变化，重新打开报告后再核验。全部原音一致仅证明检查时读到的文件字节和格式与来源一致；不证明人物标签、模型来源、分数或识别质量正确，也不安装身份阈值。

会议发言人与情绪

时间轴发言人标签可人工复核，候选声纹可辅助匹配；分段标签和已校准身份结论应分别检查。情感／情绪识别结果取决于所选分析后端和可用模型，需结合原音复核；音色工具里的情绪控制不会自动产生识别结果。

第一次登记，先完成录音检查

先在「配置引导页 → 本地模型库」登记兼容的 speaker embedding ONNX 并保存。声纹识别页填写显示名称，按名称选择已登记模型；登记、比对和会议复核共用该选择，可选 VAD 另存选择。「管理模型」返回引导页，日常使用不重复填路径。文字识别、分段与情绪分类模型不能代替声纹模型。

添加同一人的 1–8 段独立录音，每段 1–60 秒。可选 WAV、MP3、FLAC、OGG 或 M4A，再逐条点击「导入并准备」。核对原格式与派生的单声道 16 kHz PCM16 WAV 后等待信号检查；原文件保留，不裁切、不补静音。移除损坏、无变化、有效变化过短或重复录音。长静音中仅有孤立点击也不能作为声纹参考，请换一段连贯的单人讲话；低电平提示须试听。姓名、模型和合格录音齐全后才能创建。比对时也先准备独立新录音，VAD 为可选复核。

处理中可取消任务，等待取消完成再改输入。换模型后，可选原档案并用当前模型重新提取，再用独立录音比对；历史版本保留，重新提取不等于校准。

独立语音情绪分析

此工具需要 emotion2vec+ base/seed 导出的九类分类 ONNX，包含类别标签和模型元数据，例如 classifier.onnx。原始 model.pt、整个模型目录、仅输出特征的 ONNX 和声纹模型都不能代替。若手头只有原始权重，独立情绪分析仍待准备兼容分类导出模型。请先向模型提供者或管理员取得该文件；模型导出属于准备阶段，日常使用只需登记、选择。下载原始权重不会自动完成转换。准备好兼容分类器后，软件使用 Rust 与 ONNX Runtime 在本机分析，无需安装 Python；Python 仅用于管理员首次导出模型。

先在「配置引导页 → 模型与参数 → 本地模型库」把用途设为「情绪识别」，浏览模型文件。原始 model.pt 可点击「检查准备情况」查看缺项；检查不保存配置、不加载模型，也不下载文件。准备好兼容的九类 classifier.onnx 后登记并保存配置，再打开「语音工具 → 06 情绪分析」，选择已登记模型和0.25–10秒、16kHz单声道WAV。原始权重、声纹模型和只输出特征的ONNX不能代替分类器；文件检查不代表模型已成功运行。

  1. 在配置引导页打开「本地模型库」，选择用途 → 情绪识别与 emotion2vec 家族，浏览选择导出的 classifier.onnx 文件。此项优先选择文件。填写容易认出的名称，登记后保存配置。
  2. 打开语音工具 → 06 情绪分析，选择已登记的分类器。旧登记若指向 model.pt 或目录，会保留并提示「分析样本」为何不可用。点击管理模型，在引导页编辑该登记的路径，保存后返回情绪分析。不要把 model.pt 改名为 .onnx。
  3. 选择0.25–10 秒的讲话录音，可用 WAV、MP3、FLAC、OGG 或 M4A。点击导入并准备，核对原格式与派生的单声道 16 kHz PCM16 WAV，再点击分析样本。原文件保留，不裁切、不补静音；CPU 线程可先保留默认 2。仅有 .onnx 后缀不代表兼容或已成功运行，软件仍会检查分类标签、模型元数据与输出。

需要停止时点击「取消分析」，离开面板不会自动取消。使用完可点「释放模型」释放内存。回听原音并保留不确定结果；未校准分数不代表情绪强度或真实心理状态，分析不会自动改会议标签或生成参数。想调整克隆的情绪，请看语音与音色中的表达控制步骤。

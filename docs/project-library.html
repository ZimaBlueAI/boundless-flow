整理录音，再从多份记录生成灵录报告

每次录音单独保存，按项目归类。生成报告前固定文字快照，之后可逐条核对原话与录音区间。

本页 ZIP 单文件及空项目备份需 Windows r511 或后续安装预览；沿用 r510 项目词典、报告与冻结原文迁移。上述迁移功能已编入相应安装预览；安装与正常退出仍需实际验收。Mac 源码 ZIP 仍为 r492。旧图保留原版本标注；组件示例不代表原生应用或真实录音质量验收。

项目、文件夹、条目与分卷

在「会议与纪要」的会话浏览区域打开项目资料库。点击名称选择位置，点击左侧箭头展开。旧的按时间排列列表仍可展开查看。

层级示例放什么
项目家人成长一组持续整理的资料。
文件夹2026 年谈话按时间或主题分组，可继续建立子文件夹。
条目教育观察同一件事的记录，可放在项目根目录或文件夹内。
分卷亲子谈话、第二次谈话分别指向每次保存的原始记录。原音不会拼接或复制。

分卷打开后复用原有详情和编辑区域。需要核对报告引用的录音时，使用下方「原文与原声」中的区间回听。

r490 源码预览可在逐字稿片段点击整理文字，将选区或整段带入独立副本，对照结果后再复制。它不会改写分卷或报告引用。操作见文字整理工作区。

先整理已有记录

  1. 点击「新项目」，填写名称并保存。选中项目后，可点击「新文件夹」继续分组。
  2. 展开「未分类原始记录」，找到旧录音并点击「归入」。填写条目名称，选择项目、文件夹和条目类型，再保存。原始记录的位置保持不变。
  3. 同一条目需要补充已有录音时，选中条目并点「添加分卷」，选择尚未归类的记录。不要重复导入或复制原音。

选中项目、文件夹或条目后，可使用「改名」；文件夹和条目可用「移动」更换归属。归档后，勾选「显示已归档」找到原位置，点击「恢复归档」。若上级项目或文件夹已归档，先恢复上级。

跨记录找回记得的一句话

记得名称时使用名称；记得说过的话时，切换同一搜索框上方的正文。正文检索只查看本机已归类、未归档的转写，不调用模型或读取音频，也不上传资料。

  1. 先选择项目、文件夹或条目，再切换正文。在正文范围中确认全部项目、当前项目或文件夹。文件夹范围包含下级文件夹。
  2. 输入原话中连续的一小段，等待自动检索，也可按 Enter。中文按原文字面匹配，英文字母忽略 ASCII 大小写。它不理解同义词或近似意思；没有找到时，换一段更短的原话再试。
  3. 查看已核对分卷数和匹配原句。检索中可点击停止检索，或按 Esc。完成后每页最多显示 20 处，用上一页、下一页翻页。
  4. 对照结果中的项目、文件夹、分卷、说话人与时间，点击定位原句。软件会先重新核对当前来源，再打开对应转写片段；这一步不自动播放录音。
  5. 需要把相关资料用于报告时，勾选选入报告（整个条目）。核对通过后，整个条目加入原有勾选，包含其所有分卷；不会只选中命中的一句。随后按报告范围步骤核对来源，再冻结和生成。

没有结果时，先检查读取情况

看到的提示下一步
无转写、来源不可用、损坏或检索期间变化这些分卷未纳入可检索正文。先处理来源，再重新检索；没有匹配不代表这些资料没有相关内容。
记录、归属或隐私设置已变化点击「重新检索」，核对更新后的结果再定位或选入报告。旧结果不会直接打开。
所选范围超出本次检索容量缩小到项目或文件夹后重试，不把不完整结果当作全部结果。

正文检索不包含未分类或已归档条目。先归入资料库，或恢复归档，再检索。切换方式、停止或重试检索会保留原记录、报告勾选和编辑草稿；生成报告仍需你单独确认。

从条目开始下一次录音

  1. 先在配置引导准备好麦克风和识别模型。新条目可暂不归入原始记录，先保存名称。
  2. 选中条目。没有分卷时点击「开始录音」，已有分卷时点击「接着录音」。启动目标在这次操作中固定，之后改选别的条目不会改变本次归属。
  3. 出现已提交启动的提示后，查看主界面的真实录音状态。准备、录音或后台收尾期间，项目库的启动按钮会保持禁用。
  4. 在主界面点击「停止」。等待录音保存和归属处理完成，再展开条目核对新分卷。原来的分卷保留，新分卷单独保存。

启动失败时，按主界面的错误提示检查配置后重试。项目库不会因为提交失败就显示录音已经开始，也不会自动再启动一次。

先选择要整理的范围

  • 一条记录的多个分卷。选中条目，点击「生成灵录报告」。
  • 多个条目。勾选条目前的复选框，点击「已选条目生成灵录」。
  • 整个项目。选中项目或其中条目，点击「整个项目生成灵录」。

也可以先用原有的「核对条目来源」「核对已选来源」「核对本项目来源」查看分卷清单。这些按钮只核对归属；要固定转写内容并生成报告，请进入「灵录 · 项目报告」。切换资料库选择不会自动冻结、上传或生成。

冻结资料，再生成报告

  1. 进入「灵录 · 项目报告」后，先看范围名称，填写报告标题和语言。
  2. 选择资料纳入方式。默认「全部资料（须全部完成）」要求所选文字来源全部就绪。如果有转写未完成或资料缺失，先等处理完成；也可主动选择「只使用已完成资料」，再点击「冻结并核对资料」。不会自动改为部分资料。
  3. 查看「核对冻结资料」。逐份确认已完成、未完成或缺失状态，并核对未纳入的归档、无录音条目。这里的“全部”指所选文字来源完整，不保证每份录音都可回听。缺少音频时，文字仍可纳入，回听入口会提示不可用。部分范围会明确标注遗漏。
  4. 查看正在使用的会议模型。需要更换时点击「管理会议模型」，复用已有会议配置；这里不需要重新填写模型地址和密钥。冻结操作只保存本机快照，还没有生成报告。确认后，单独点击「生成报告」，已纳入的资料才会发给当前会议模型。
  5. 生成期间可查看阶段和进度，或点击「取消报告任务」。切换条目、隐藏界面不会改变本次任务的范围；返回时可查看同一个后台任务。失败或取消后，资料与草稿保留，重试需要再次点击。

在「已保存报告」中点击标题，可打开本机报告，无需重新生成。点击「导出报告 HTML」选择保存位置。导出文件保留报告文字和来源引用，不会自动附带录音文件。

声光拾忆 · 把几次讲述整理成回忆录

本节回忆录步骤需 Windows r512 或后续安装预览。先按上面的单条、多条或整个项目入口选好资料，再冻结来源；不必搬动录音或重新配置模型。

  1. 在项目报告里核对已冻结的范围和未纳入资料。「报告形式」选择声光拾忆 · 回忆录，「编章方式」选择按所选来源顺序编章或按主题编章。
  2. 来源顺序适合逐次查看已选录音；主题编章适合把同一话题放在一起。录音日期只说明何时录下这段话，不等于故事发生日期。没有事件日期时请保留不确定信息。
  3. 确认标题、语言和现有会议模型后，点击生成报告。等待任务完成，再核对每章的整理文字及来源。点击章节标题可折叠或展开。
  4. 点击编辑回忆录，再用上移章节、下移章节调整顺序。更改先保留在当前草稿中，不会移动原始录音或改写引文。
  5. 修改「修订标题」、章节标题或整理正文。每个已有章节、段落和引用都须保留；标题与章节名最多各 160 字，每段正文最多 1,600 字。原话、来源与时间只读；点击引文仍可回到冻结原文并按需载入原声。
  6. 核对后点击另存新版本。编辑后的正文标为「人工修订」，旧版保留。可点击查看上一版，或从「已保存报告」打开旧版。新版本不会覆盖原录音或原转写。

每一段整理正文仍带着原有引用。若引文本身有误，请回到会话核对原始转写，再重新冻结和生成；不要在章节编辑里改写原话来配合故事。

切换报告或结束编辑时，未保存的修订会先提示处理。需要保留就先另存，也可明确放弃草稿。另存失败时，当前草稿与旧报告仍保留，请按提示核对后再重试。

沿用原话、情绪依据与原声核对的操作。有保存元数据时，可在来源区查看录音开始时间；旧资料可能没有这项。模型情绪标签与人工选项分开显示。没有可用依据时不补写情绪、心理活动或故事细节；同名人物、矛盾说法和不明日期仍需按各自来源核对。

需要分享时导出当前版本的 HTML。文件保留整理文字与来源引用，不会把全部录音打包进去。

把已保存的独立情绪观察带入报告

本节历史观察步骤需 Windows r512 或后续安装预览。已有的模型路径仍在配置引导页管理，报告中无需再配一次。

  1. 在会议记录中选中片段，展开专用情绪模型分析，选择已登记的 Emotion2Vec 分类器。核对片段内 0.25 至 10 秒的分析区间，点击分析并保存，等待结果保存到会议。
  2. 回到项目报告，点击冻结并核对资料。冻结只收录当时已保存的独立观察，不启动情绪模型，也不补做分析。先前冻结的报告需要重新冻结、生成新报告，才会包含后来保存的观察。
  3. 生成报告后，展开附录 · 独立情绪观察，再展开一次分析。这里仅列出正文引用片段的已保存观察。点击查看该片段原文，在来源详情中展开Emotion2Vec · 已保存声学观察，可查看该来源全部冻结观察；超过 12 条时翻页。
  4. 核对候选类别、九类原始分数与模型版本，再对照原文和录音。每次分析单独保留，区间、原声区间 SHA-256 和模型 SHA-256 均可查阅。另存回忆录新版本会保留这些观察，原有分析记录不会被正文编辑覆盖。
看到的依据怎样阅读
SenseVoice 标签转写时保留的模型候选，仍须结合原音复核。
人工选项单独保存的人工标注，也可能主动选择未知。
独立 Emotion2Vec 观察你主动运行并保存的声学分析，可能与前两项不同，不会自动替换它们。九类原始分数未校准，不是情绪概率、准确率或强度。

独立观察在本机来源详情和报告附录中展示，不发送给报告模型。它不能证明人物身份、真实心理或故事里的情绪。

先看是否收录，再看原声核对状态

界面提示表示什么
历史快照未收录当时的快照没有这项资料，不能据此判断已分析或结果为零。
本次核对无已保存观察冻结时检查过该来源，没有可收录的已保存独立观察。
冻结时原声区间与哈希一致冻结当时读到的区间与分析记录吻合，不能证明模型结论正确。

报告显示的是冻结当时的核对结果。之后回听使用当前标准化录音的实际区间，不会重新认证历史观察。需要分析新音频或采用后来保存的结果时，先在会议片段中分析并保存，再重新冻结、生成报告。

把报告与原话放在一起核对

此阅读布局需 Windows r512 或后续安装预览；Mac r492 源码 ZIP 尚未包含。

  1. 点击报告正文下的来源和时间。宽容器中报告与冻结原文并排；窄容器使用报告正文 / 引用依据切换。依据区同时保留对应报告段落，方便对照。
  2. 自动定位被引用片段及所在原文页。报告、来源及逐字稿分别保留阅读位置；点击返回报告引用或收起原文可回到刚才的引用。
  3. 需要听时再点载入本段原声。播放器在逐字稿上方，不自动播放；仍按原有方式读取有界实际区间，不是整场录音播放器。
  4. 编辑回忆录时，依据区显示当前未保存段落；核对引用不会保存或放弃草稿。展开来源时间与回听说明可看录音元数据和当前音频核验边界。

逐条核对原话、情绪依据与录音

  1. 点击正文下的来源名称和时间，打开对应分卷的冻结原文。同样叫「s1」的片段也会按各自来源分开，不会混在一起。
  2. 对照原话、说话人和时间。原始转写也可能识别有误，并非人工核准的准确答案。正文中的「AI 整理」和「模型观察」需要你复核，不能用来确定身份或心理状态。
  3. 查看情绪依据。「模型标签」保留模型观察；「人工选项」单独显示已保存的标注、未知或沿用原模型标签。两者可能不同，不代表情绪强度，也不代表人工已确认模型正确。独立 Emotion2Vec 的已保存结果请按上面的独立观察与原声核对步骤查看。
  4. 需要听录音时，点击「载入本段原声」。长于 10 秒的片段可载入前 10 秒、后 10 秒，或填写起点。每次载入的是 16 kHz 单声道录音中的 0.25 至 10 秒实际区间；末尾不足 10 秒时按实际长度提供，不补齐。播放器不会自动播放，请核对界面上的确切时间后再点播放。

回听使用当前的标准化录音文件，不是原始设备文件，也不能证明这段音频与过去完全相同。缺少音频不会隐藏冻结文字。若原文后来修改，界面会提示仍在使用冻结版本；姓名撤回或隐私设置变化后，旧来源会停止使用，需要重新核对资料。

「资料覆盖与遗漏」会分别列出已引用、已处理但未引用、未送入模型的资料。没有出现在正文中，不等于没有处理，也不等于已被证明不重要。

出现提示时怎样处理

  • 资料库已更新。当前草稿会保留。点击「刷新」，核对新位置和内容后再保存；不会自动用新版本覆盖你的修改。
  • 录音已保存，需要核对归属。先刷新资料库并查看目标条目。若记录仍在未分类列表，使用「添加分卷」手动归入；若已有正确归属，直接保留。不要先删除原始记录。
  • 保存通知到来时仍在编辑。草稿不会被清空，资料库也不会自动跳到新版本。先刷新核对，再继续编辑。
  • 未看到新分卷。先等待主界面的收尾结束，再刷新。不能仅凭启动已提交就判断录音已保存。

需要生成单次会议纪要时，继续使用会议与纪要或灵录主题纪要的现有入口。

定期归档：让过期导出副本有归处

需要 Windows r513 或更高版本。r512 及更早安装预览不包含定期归档。原有手动核对、确认移动方式继续保留。

  1. 在资料库右下角打开存储管理，找到「缓存归档方式」。默认是手动；第一次使用可先保留手动，按原有步骤核对可整理项。
  2. 需要自动检查时，将「归档方式」改为定期归档。选择后自动保存，看到「已保存」状态即可，不用保持存储窗口常开；软件仍需运行。
  3. 点击读取归档状态，查看下一次计划、最近一轮的结果，以及归档目录。忙碌、录音、退出或已有其他任务时会跳过这一轮；失败后退避再试，不持续高频扫描。
  4. 随时可改回手动，之后不再安排自动轮次。修改模式不会中断已经开始的一轮；先看当前状态，再决定是否手动处理归档目录。

默认每 60 分钟检查一次；软件启动或启用后先等 5 分钟。只考虑超过 30 分钟、已经核验、没有活动任务引用或文件占用的新版本导出核对副本；不是对整块磁盘做清理。

不会删除文件，移动也不会释放磁盘空间。本次可整理的副本移到显示的「可删除」归档目录后，你可以在核对结果后自行处理该目录。模型、原始录音、历史、报告引用依据、待处理或失败资料、未完成的 .zip.partial 及未核验的孤立工作副本都不在这次定期归档范围内。

阅读逐字稿，跟随原声核对

在「会话浏览 → 逐字稿预览」，默认直接阅读每段正文。时间、说话人、整理文字和编辑放在同一行，短句不再占据大块输入框。此改进从 r492 提供。

  1. 点击「编辑」修改本段正文或说话人，再用「保存文本」或相应的改名按钮保存。「收起编辑」会保留草稿；「恢复」用于放弃本地修改。
  2. 点击段落时间，从这一段开始回听原声。可暂停、停止，或勾选「接续播放」听后续片段；原声缺失或暂不可读时，文字仍可阅读。

高亮按片段时间切换，不是逐字精确对齐。「接续播放」从下一片段的起点继续，不包含未选中的段间空隙。正在录音、尚未保存的内容不提供这种原声回听。原声留在本机，仅在点击播放后按需读取。

把导出资料迁回项目资料库

r507 源码预览。在新电脑或另一份资料库中继续整理此前导出的项目。只读取你选择目录中清单列出的文件，不调用模型、不上传资料；原目录与当前已有记录保留。

  1. 找到完整的 Boundless Flow 导出目录，里面应有 manifest.json、manifest.sha256、records 文件夹及 JSON。TXT 或 SRT 不能单独恢复项目层级；没有 JSON 时请回原资料库重新导出并勾选 JSON。要一起迁移声音，原导出需勾选“包含保存的原音副本”。
  2. 在项目资料库上方点导入资料 → 选择 ZIP / 选择目录 → 核对导入资料。核对会读取清单、文字和文件校验值；不会在此步骤导入。录音或语音任务进行中，请先结束当前任务。
  3. 核对项目名称、分卷数量、项目词典、已保存报告及未纳入报告数、携带原音、纯文字分卷、预计空间及资料库所在盘的可用空间。有未包含项、未纳入报告或缺音时，勾选确认后才能继续；纯文字分卷仍会保留原话、时间和已保存标签。
  4. 点导入为新项目。项目、文件夹、条目和分卷使用新编号，不按同名合并、不覆盖已有录音；分卷顺序保持。已保存的人工情绪选项与独立 Emotion2Vec 观察分别保留。历史观察显示原日期和模型，标明“导入保留”，本次不会重新推理。

  6. 重复选中同一完整导出目录时，点找回已导入资料只返回原来的编号，不再创建副本或覆盖后续编辑。若提示完成上次导入，会先核对已经复制的文件，再完成登记；不是开机自动续做。

词典、报告和原话一起迁移

Windows r511 或后续安装预览已包含 r510 的这些项目迁移功能。沿用上方的导出与导入步骤，无需再配置迁移选项。

  1. 导出时保留 JSON 勾选。新版项目包自动携带项目词典及已有历史，以及本次范围内可用的已保存报告和生成时冻结的原文。仅导出 TXT / SRT 不携带这些资料。
  2. 核对词典、报告和未纳入报告的数量。某份报告涉及范围外的条目，或暂不可用时，不会悄悄补入范围外资料；可扩大选择范围后重新核对。有未纳入报告时，确认未纳入数量后才能继续。
  3. 导入后打开新项目的项目词典与历史，核对词条及已有历史；原项目和全局词典保持原状。在已保存报告中打开迁入报告，不必重新生成。
  4. 旧报告保留生成时的原文与引用，当前逐字稿保留后来保存的修订。二者不同时分别核对，不会用新文字替换旧引文。导出携带有效原音时，可继续从引用回听；没有携带原音时，仍可阅读报告和原话。
  5. 看到“旧版项目包”提示，表示当时未携带词典和报告，不是此次导入丢失。需要这些内容，请在原资料库使用新版重新导出 JSON 项目包。

请保留整个项目包，不能只复制其中的报告或词典文件。目录校验失败时不会把报告显示为已迁入；先回原资料库核对并重新导出。

查看占用，核对后整理缓存

点主窗口上方的存储管理。也可在配置引导的音频缓存位置中点查看存储占用。统计使用已保存配置，尚未保存的目录草稿不会生效。

  1. 点统计存储。软件只检查本身资料和已登记目录的文件大小，不加载模型、不读取音频内容，不扫描系统临时目录。模型文件多时较慢，需要时才勾选同时统计模型目录大小。
  2. 查看历史录音、报告依据、中断录音、导出缓存、项目资料、待处理、失败、未核验分片和模型。展开查看位置可复制目录。路径缺失、链接或达到统计边界时会显示“不完整”和大小下限；不是已核验的空目录。
  3. 查看应用资料和分片缓存所在盘的当前可用空间。需要换盘时点调整后续录音缓存位置，进入配置引导保存。修改只影响新录音，不迁移已有录音。
  4. 点核对可整理项。当前只纳入新版导出创建、已有完整归属与内容校验、超过 30 分钟且无活动引用的缓存。失败、处理中、被修改和未核验的资料不自动归档，旧报告引用依据也保留。
  5. 核对数量与位置，勾选确认后点确认移动归档。核对在 5 分钟内有效，移动前会再次检查。达到本批统计边界时，可处理本批后再核对其余缓存。
  6. 查看已移动和保留的实际数量。移动归档仍占用原盘空间；软件不会自动物理删除。复制归档位置后由你手动决定何时处理，软件不再读取或复用归档内容。

关闭这个窗口会继续后台任务；再次打开可找回状态。任务状态读不到时点核对当前任务，不会重复启动检查。需要停止时使用停止本次检查；正在进行的磁盘读取要返回后才能结束。本功能没有跨重启续做，也没有定期物理清空。

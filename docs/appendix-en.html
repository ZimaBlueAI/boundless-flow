Starting the correct version

Open Boundless Flow or your app shortcut. The main window should show version 0.5.0. Start with Setup Wizard on first use; on later sessions, open the tool you need.

If an older version is open, close the unwanted instance and open the current version. App, model and data locations are configured separately. Check companion components before moving the app, and check references before moving models.

Configuration, original audio and storage

Use the app backup/recovery flow to choose a configuration candidate explicitly. Model preparation adds a native package within the model directory; linked original weights remain dependencies and must not be moved arbitrarily. Back up app data, meeting audio, imported references and exports separately.

Meeting audio, imported references, models and exports all use disk space. Check whether the app still references a file before backing it up or moving it. Moving files on the same volume does not free space. Archiving a voice or voiceprint only hides its entry; it does not delete recordings.

Include in a bug report

Include the version and launch entry, steps, failing stage, model family and full directory, failed file and complete error. Do not include API keys or private audio in screenshots. For performance, state session duration, language count, models, input/output devices and the slow stage; do not infer interpretation latency from total request time alone.

Offline watermark results

The platform operator can use the separate Boundless Flow offline audio watermark decoder to inspect a WAV file. Select the audio, configure the matching private key and slot on the operator’s offline machine, then read the result. No recording is uploaded, and no private key is configured in the ordinary voice tools.

The result shows the generation ID, unique-record count and verified-packet count. A record can repeat within the audio, so verified packets can outnumber unique records. Open the details only when troubleshooting FFT, authentication or protocol information.

“Boundless Flow audio watermark detected” means an authenticated software-provenance record was recovered; it does not establish the speaker’s identity. “Not detected” does not prove human speech. Cropping, transcoding or short audio can prevent recovery. Recovery after lossy conversion such as MP3 is not guaranteed.

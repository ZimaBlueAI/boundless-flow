同传工作台 / 云端语音翻译

边讲话，边听译声

在同传工作台选择「连续同传 · OpenAI」，让服务持续接收麦克风声音，返回目标语言的译声和字幕。此路线需要网络和可用的 OpenAI API 账户。

选哪条路线保存连接开始与停止支持的目标语言字幕与导出常见问题

先选适合的同传路线

你需要什么选择准备内容
使用自己的本地识别、翻译和译声模型分段译声选择已配置的 STT、翻译和 TTS，按需使用参考音。见同传工作台教程。
由同一云端模型持续听入语音并翻译出声连续同传 · OpenAI选择已保存的 OpenAI 连接和一个目标语言，无需另选本地 STT 或 TTS。

连续同传使用 gpt-realtime-translate 的专用翻译接口。源语言由服务自动判断。每次会话输出一种目标语言，当前入口使用一条麦克风音轨。

译声会随来源声音的整体语调、音高和表达风格变化。这一能力不保证精确复制说话人的身份或声纹，也不提供固定音色、参考音上传和自定义提示词。接口说明见 OpenAI 连续翻译指南。

在配置引导中保存一次连接

  1. 打开顶部「配置引导页」，进入 API 配置，找到 OpenAI。
  2. 填写账户的 API Key 和 Base URL。官方地址为 https://api.openai.com/v1；实时模型填写 gpt-realtime-translate。
  3. 启用并保存连接，再返回同传工作台。使用时从已配置的连接中选择，不需要反复输入地址或密钥。

使用兼容服务时，服务必须实现 OpenAI 的专用连续翻译协议。仅支持文本对话、文件转写或语音对话的兼容地址不足以运行此功能。不要把 Qwen、豆包的专用语音地址填进来，也不要在 Base URL 后追加 /realtime/translations。

此路线会把麦克风音频发送到所选服务，并接收译声。开始前请确认服务地址、账户权限和计费规则。软件不会自动换用另一家服务。

开始讲话，停止后等尾句播完

  1. 打开「同传工作台」，选择连续同传 · OpenAI。戴上耳机，避免扬声器的译声再次进入麦克风。
  2. 选择已保存的 OpenAI 连接，在译成中选择目标语言。源语言保持自动；若需要同时阅读来源内容，勾选同时显示源语转写。
  3. 点击开始连续同传。先等待连接、配置确认和设备准备完成，再开始讲话。看到「正在收音与翻译」后，观察麦克风电平，确认输入正在变化。
  4. 按平常节奏讲话，句间可以正常停顿。服务持续处理音频，译文和译声会陆续到达。
  5. 结束时点击停止同传。收音停止后，已经发送的尾句仍可能返回字幕和音频。等状态结束、尾音播完后，再开始下一次。

关闭同传面板会继续运行。需要结束收音时，先点击「停止同传」。单纯收起面板或切换查看内容不会替你结束会话。

没有固定的出声时间保证。网络、语言组合、说话节奏和服务负载都会影响等待时间。建议第一次先说一句短话，确认源字幕、目标语言和译声音量，再用于较长的内容。

来源声音里的混合语言、专有名词、数字和多人重叠讲话，仍需要人工核对。自动判断语言不意味着能正确翻译所有录音。

阅读字幕，保留完整记录

来源字幕和译文分别追加显示。字词可能分几次到达，软件按服务返回的顺序接起来；句子尚未完成时，不要只凭一个字判断翻译结果。

原文和译文窗口各保留最近 32 KiB 的 UTF-8 文本，能显示的字数随语言而变化，较早内容会移出阅读窗口。停止会话后，使用导出记录 · JSONL保存本次会话的完整字幕事件；运行中不能导出。JSONL 是逐行存储记录的文本格式，可用文本编辑器查看。「复制窗口」只复制当前保留的文字；浏览较早内容后，可点「回到最新」继续跟随字幕。

记录包含目标语言、字幕片段及会话状态，不包含原始音频，也不会自动生成 WAV 文件。记录随软件的数据目录保存。退出软件会取消当前同传；请先正常停止并等尾句处理结束，再退出。

源字幕关闭时，不会显示这条来源转录流。译声和目标字幕仍来自语音翻译；来源转录本身可能与实际讲话有出入。

遇到问题时先看这几处

现象处理方法
找不到可选连接回到配置引导，确认 OpenAI 连接已启用、已保存，实时模型为 gpt-realtime-translate。
一直停在连接或配置确认确认账户有该模型权限，Base URL 可用且服务实现专用翻译接口。界面未进入收音状态前，不代表已经开始发送讲话。
电平没有变化检查系统麦克风权限、当前输入设备和硬件静音。先用配置引导的麦克风检查确认输入。
有字幕，听不到译声检查系统输出设备、耳机音量和应用音量。先等短句完成，再确认是否仍没有声音。若讲话本身已是目标语言，服务也可能不播报。
译声又被翻译了一次戴耳机并降低扬声器回放，避免回声进入同一条输入音轨。
提示连接断开或服务错误保留已有记录，检查网络和账户后由你重新开始。软件不会自动重连或切换服务；断开期间的讲话不会自动补传。

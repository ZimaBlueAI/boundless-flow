启动与版本

打开 Boundless Flow 应用或你创建的应用快捷方式。主界面显示的版本号应为 0.5.0。首次使用从「配置引导页」开始；后续使用可直接进入相应工具。

若打开了旧版本，先关闭不需要的应用实例，再打开当前版本。程序位置、模型位置和数据位置分别配置；移动程序前检查配套组件，移动模型前检查引用路径。

常见提示

功能／提示使用说明
s2mel 权重带 net. 前缀当前选择原始 Index 权重；先准备原生模型，完成后使用自动切换的 .boundless-flow/native。
缺少 gpt／s2mel／feat／semantic_codec／bigvgan 等文件区分原始目录与已准备目录；按检查结果补齐来源权重，再准备。不要用空文件或改名掩盖缺项。
index_checkpoint_unsupported_or_invalid记录失败文件、pickle_global、offset、protocol 和模型版本。原文件保留；更新组件或定位格式后再试，该提示表示当前组件无法读取此检查点格式。
缺少 audiovae.safetensorsVoxCPM2 原生包需要该文件；按原生准备流程处理配套权重。
参考录音须 1–60 秒更换录音或显式选择合格讲话区间，不补静音、不改写原始录音。
expected mono 16000 Hz WAV先在音色工具显式导入转换；声纹登记仍应提供界面要求的合格 WAV。
无法在模型目录内准备检查该盘剩余空间、目录写权限和是否只读；不自动转存 C 盘。
API 401／403／模型不可用确认能力专用鉴权、服务地址和账户可用模型；保存成功不是接口验证。

配置、原音与空间

使用软件内的配置备份与恢复功能明确选择候选。模型转换仅在模型目录内新增原生包；需要关联的原始权重仍是依赖，不可随意移走。应用数据、会话音频、导入参考和导出结果也需分别备份。

会话音频、导入参考音、模型文件和导出结果都会占用磁盘空间。先确认文件是否仍被软件引用，再备份或移走；同盘移动不会释放空间。音色和声纹的「归档」只隐藏条目，不删除录音。

反馈问题应包含

提供版本和运行入口、操作步骤、出错阶段、模型家族及完整目录、失败文件与完整错误。API Key 与私人音频无需放入截图。性能问题说明会议时长、语言数、模型、输入／输出设备和哪个阶段耗时；不要只用总请求时间推断同传延迟。

离线水印结果

平台方可使用单独的 Boundless Flow 离线语音水印解码器检查 WAV。选择音频，由平台方在自己的离线设备上配置对应私钥和槽位，再查看结果；无需上传录音，也不需要在普通语音工具中配置私钥。

结果区显示生成 ID、唯一记录数和已验证包数。同一条生成记录可以在音频中重复出现，因此已验证包数可能大于唯一记录数。排错时再查看详情中的 FFT、认证和协议信息。

“检测到 Boundless Flow 语音水印”表示恢复了通过认证的软件来源记录，不证明说话人的真实身份。“未检测到”也不能证明音频是真人原声；裁剪、转码或过短的音频可能无法恢复水印。目前不保证经过 MP3 等有损转码后仍能恢复。

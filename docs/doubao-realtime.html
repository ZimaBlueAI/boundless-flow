豆包语音 · 实时转写

边说边看文字，由豆包语音服务自动分句、确认最终结果。先在配置引导保存连接，录音时选择已保存的服务。

先保存连接，再开始录音

先在配置引导保存豆包语音连接和已开通的识别资源，再到录音页面选择服务。更换资源仍回配置引导保存，无需在多个页面重复填写密钥。首次使用请用自己的账号和录音设备录一小段，确认权限、识别效果与费用；速度和质量取决于服务、网络及录音条件。

开始前准备

  • 开通豆包语音实时识别所需的服务与资源，准备新版语音控制台提供的 API Key。可能产生服务费用，以控制台和账单为准。
  • 确认所选录音输入能录到需要的声音，网络可以连接服务。该路径会持续发送音频，不需要下载本地识别模型。

第一次使用：按顺序设置

① 配置引导 · API② 保存豆包语音③ 实时 API · Doubao④ 语言自动 · 开始录音
  1. 打开「配置引导」→「API 配置」。 选择「豆包语音 · 实时识别」。这是独立的语音连接，不是方舟文本服务；已有方舟配置不会自动提供这条连接的密钥。
  2. 保存服务地址和语音 API Key。 HTTPS 根地址填 https://openspeech.bytedance.com，填写新版语音控制台的 API Key。不要填方舟地址、把文本服务 Key 当作语音凭据，或自行拼 OpenAI 兼容路径。
  3. ASR 资源选择自己已开通的一项。 volc.seedasr.sauc.duration 或 volc.seedasr.sauc.concurrent。两者都需与账号权限匹配；只在这里配置一次，随后完成引导并保存。
  4. 在「录音设置」选择已保存的服务。 「录音识别方式」选「实时 API」，「已保存的服务」选 Doubao / 豆包语音。页面复用已保存的地址、资源和密钥；已在配置引导保存的 ASR 资源仅供查看，不在录音页面重复填写或修改。
  5. 源语言选「自动」，语言提示留空。 此双向接口不支持强制指定识别语言。如果之前选了中文、英文等固定源语言，请改回自动；翻译目标语言属于另一项配置。
  6. 说一句话，再点击「停止」并等待。 回到实时字幕点击「开始」。说话过程中可看到临时文字，服务端确认后得到最终句；停止采集后，还要等待最后的确认结果和任务完成提示。

更换资源：只在配置引导修改

  1. 在「录音设置」的实时 API 区域点击「管理服务」，直接打开「配置引导」的「API 配置」步骤。
  2. 找到「豆包语音 · 实时识别」，修改 ASR 资源、地址或语音 API Key，完成引导并保存。资源只选择账号已开通的 volc.seedasr.sauc.duration 或 volc.seedasr.sauc.concurrent。
  3. 返回「录音设置」，确认选择的是豆包语音，并核对显示的资源。保存的更新用于下一次录音；正在进行的录音不会中途切换服务或资源。

如果提示「模型配置已更新」，请刷新设置或重新选择服务，再开始新的录音。若显示的资源无效或未开通，请回「管理服务」纠正后保存；程序不会静默改成另一项资源或重发音频。

这条路径怎样工作

服务端自动分句使用豆包服务的分段结果；本地 Silero 或逐句切分不参与这条路径。
临时文字会变化以后续确认句为准，草稿不会被当成最终记录。
停止后继续收尾停止麦克风采集后，仍需等服务端确认最后结果。

停止采集后的确认尾句仍会补入字幕和会议记录；已启用翻译时，也会提交该句继续处理。停止后不再向其他窗口输入文字。请等本次任务完成后再开始下一次录音；未确认的草稿不会作为终稿补入。

遇到问题时怎么做

已保存方舟，为什么还要配置豆包语音？
两者的服务地址、凭据和资源不同。这里使用 bigmodel_async 专用双向音频协议，不是 OpenAI 兼容文本接口。请在「管理服务」打开的 API 配置中保存正确的语音连接，不在录音页面重复设置。
资源框不能编辑，或提示资源不支持
这是配置引导中已保存的资源。点击「管理服务」，将 ASR 资源改为已开通的 duration 或 concurrent 完整编号，保存后返回并重新选择服务；不要填方舟模型名。
提示语言不支持
将录音源语言改为自动，并清空语言提示，再开始新的录音。本接口不能靠填 zh 或 en 强制识别语言。
权限错误或没有确认结果
核对语音控制台 Key、已开通资源、账号状态和网络。更换方舟文本模型不能解决这条语音连接的问题。
断网、失败或停止后未收齐
原始录音和已确认结果保留；未确认草稿不会补成最终结果。程序不会自动重试、重连或重发音频。处理错误后，如需补转写，可手动导入已保存录音，使用单独的文件转写流程，并确认服务与可能费用。

这项功能的范围

本次接入只增加豆包语音实时 ASR / STT，不代表已经接通完整同声传译、声音克隆、语音合成或录音文件上传接口。翻译、译声与灵录报告仍使用各自的服务与设置。

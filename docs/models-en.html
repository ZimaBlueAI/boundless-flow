Models & APIs

Find a model for your task, check its supported route, then save its settings once in Setup.

This catalogue describes the routes implemented in Boundless Flow 0.5.0. A listed model is not necessarily bundled, installed or available to your account. Expand a card before downloading or configuring it.

01

Start with a short test

For Chinese transcription, start with SenseVoice. For local cloning, use a prepared Index model, Qwen Base or VoxCPM2. For voice design, choose Qwen VoiceDesign. Test one target language before combining transcription, translation and speech in the interpreting studio.

Open the setup guide →
  1. 1Register the model or API in Setup
  2. 2Run a short recognition, translation or voice test
  3. 3Save it, then select the saved entry in your workbench
Local models: CPU or NVIDIA GPU?

Obtain model files separately. In Setup, check the selected model's components and device before choosing CPU or NVIDIA GPU; device support differs by engine. After the checks pass, generate a short voice sample.

The Windows r469 native CUDA component includes code for compute capabilities 7.5, 8.0, 8.6 and 8.9, plus a PTX forward-compatibility path. VoxCPM2 generation has been verified on RTX 4090. Other GPUs and models still need a short trial; this does not establish universal compatibility. Before loading a model, the app checks the GPU, driver and component. If a check fails, choose CPU in Setup. FireRed currently uses CPU.

For local Windows installation, use the NSIS installer or the r475 locally test-signed MSIX. The old r468/r469 unsigned previews cannot be installed directly. For local MSIX testing, explicitly trust its matching public CER first; this does not establish Microsoft Store certification. Local MSIX installation steps → Installation and first setup →

What the labels mean
Native
A local inference route is implemented. Matching model files and native components are still required.
Compatibility
Uses a dedicated or legacy runtime; some advanced features remain here.
Service
Connects to an already running service or cloud API. Models and permissions come from that service.
Experimental
An entry is implemented, but full product acceptance is incomplete.
File checks only
Checks files or identifies a model; no inference through this entry.
Template only
Saves configuration fields; the corresponding audio protocol is not implemented.

Implemented protocols still need a working endpoint and account permissions. This catalogue does not claim that every provider account has been tested.

iFLYTEK · Realtime ASR Large Model

Choose automatic Chinese/English/dialect recognition or multilingual recognition with separate entitlement.

Setup & limits
Configure once
In Setup → API, save this product’s App ID, API Key and API Secret with the complete /ast/communicate/v1 endpoint. Choose a named mode, save, then select the service in Recording settings. The saved mode is read only there.
Language & previous settings
Chinese/English/dialect mode requires Auto source and empty hints. Multilingual supports 37 documented languages and needs separate permission. Classic RTASR/IAT values remain visible as a previous configuration and require deliberate migration.
Completion & availability
Stop drains the remaining audio and waits for final confirmation; failure does not automatically reconnect or resend. Normal meeting storage retains original audio for retranscription; check the disk if a storage warning appears. Provided in the next source update; the current Windows r475 installer does not include this route. Live-account accuracy and latency are not established.

Doubao Speech · Realtime ASR

Stream speech for server segmentation and confirmed text through a connection separate from Ark.

Setup & limits
Configure once
In Setup → API, save openspeech.bytedance.com, a speech-console key and an enabled volc.seedasr.sauc.duration / volc.seedasr.sauc.concurrent resource. Select Realtime API → Doubao when recording to reuse the connection.
Language & completion
Use Automatic source language and empty hints. Server segmentation and final confirmation continue after Stop. Disconnection retains the recording without automatic retry/resend or promoting drafts.
Availability
Included in the r468 candidate. Save the model in Setup, select the service when recording, and use Manage service to change it. Account access, billing, recognition, physical devices and performance remain unverified. Separate from full interpreting or cloning, with no fixed-latency promise.

Service API

Aliyun · Paraformer

Stream speech and receive interim text and server-confirmed sentences.

Setup & limits
Setup
Setup → API: save the Beijing endpoint, key and paraformer-realtime-v2. In Recording settings, choose Realtime API → Aliyun · Paraformer and reuse the saved credentials.
How it works
16 kHz mono PCM; approximately 400 ms server pause threshold. Stop still waits for task-finished. On failure, the original recording is kept without automatic reconnection or resend.
Availability & acceptance
Realtime transcription is included in r466; the r468 candidate centralizes model settings so recording selects the saved service. Protocol and local simulated connections were checked; paid-account and physical-microphone acceptance remain pending. Separate from file ASR, cloning and full interpreting.

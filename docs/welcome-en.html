Tools and operating modes

Use the header to open the setup wizard, recording settings, voice tools, interpretation or floating transcription. The voice panel has six task entries for audio files, model setup, timeline speaker names, speech synthesis, audio output and emotion analysis. Choose the one you need.

Local models need complete packages, matching native components and enough memory. Model services need a running server and the matching protocol. Cloud APIs need an account with the appropriate capability. Start with one route; there is no need to configure every service.

Before you start

This guide covers the 0.5.0 desktop app. Check model files and service connections, then test recording, translation and speech on your devices. Follow the on-screen guidance for experimental or unavailable features. Recognition quality and interpretation latency vary with models, languages and devices.

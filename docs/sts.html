统一译声配置

在「译声配置」选择本机原生模型、克隆模型服务、语音服务／API 或兼容配置。选择运行方式仅启用对应链路，保留其他来源的模型、参考音与密钥草稿。CosyVoice3／Fish 在此提供本机与服务选项；本机需要匹配的完整原生包与运行组件，真实生成仍待验证，不能直接使用官方原始目录。

持续同传和 Mini 译声不加入语音水印，省去水印处理和缓冲等待。语音工具保存的普通克隆音频仍可带来源水印。实际出声速度还取决于模型、翻译服务和音频设备。

旧配置同时启用多条链路时会显示提示；请先明确选择一项，再开始任务。准备、运行、停止与收尾期间不能切换运行方式。

  1. 先在配置引导页保存本地模型路径。不同大小或量化分别命名、登记规格；需要时将 VoxCPM Runtime 随模型保存。
  2. 工作台选择运行方式 → 本机原生模型，再选择已保存的持续克隆译声模型，不必重新填写路径。需要新增或更改登记，点击管理本地模型进入配置引导页。
  3. 本次任务使用工作台当前选中的模型，主界面已保存的模型可以不同。换用另一登记项后，先核对显示的名称与规格，再用短讲话验证识别和译声。选择本次任务的音色库参考和计算设备。检查模型与参考录音，再用目标语言短句试音，确认后开始持续同传。

先检查三条链路

  1. 识别：在引导页登记并检查 STT 模型，工作台选择该模型及源语言；确认输入设备，用短讲话验证原文。
  2. 翻译：在引导页保存服务地址、模型和鉴权并做文本测试；工作台选择已配置的「翻译服务」和目标语言。
  3. 合成：在引导页保存模型或服务连接，工作台选择已配置的译声来源、音色与参考音；使用目标语言短文本先试音。

本次语言与前文背景

适用版本：Windows r512 或后续安装预览。更早安装预览不含本节的语言与上下文修复。以下设置作用于翻译请求，仍需自行核对原文、译文与译声。

  1. 开始前，在同传工作台核对本次源语言与目标语言。例如中文讲话、英文译声，选择“中文 → 英语”。软件界面使用中文还是 English，都不能替代这两个选择。识别、翻译和译声分别检查后，再开始本轮任务。
  2. 如果需要前文帮助理解指代或术语，在翻译设置展开术语与翻译背景，将最近原文背景预算（0 为关闭）改为大于 0 的适合值，保存后再开始新任务。默认 0 不带前文；留为 0 也可以正常逐段翻译。
  3. 分段译声与已保存音频的逐段翻译，在启用背景后，复用本任务内此前成功翻译段落的原文。例如前段介绍“这是无界音流”，后段说“它可以记录会议”，前段原文可作为后段的翻译背景。
  4. 背景只帮助理解当前段，不包含前段译文，不把背景再翻译一遍，也不跨任务串用。开始另一轮任务，会从该任务自己的背景开始。若预算放不下全部前文，只保留能纳入的最近原文，不为凑预算截断当前原文。

启用背景会把相应前文一并发给所选翻译服务。主录音设置里的检查术语与请求（不调用模型）绑定该页的当前识别设置与主翻译目标，而且不含会话上文；它不是同传任务的完整历史预演。更换语言、引擎、目标或模型后，请重新检查，并在同传工作台再核对本次选择。详见识别、翻译与界面语言的区别。

连续同传

从顶部打开「同传工作台」，检查源语言、目标语言、字幕额外语言与输出。点击连续运行后等候准备状态；支持预加载的组件会先准备声音模型，不支持时界面提示首句加载。准备阶段可停止取消。

工作台自动播放译声。使用 Rust 流式播放或模型服务的「音频到达即播放」时，录音前会先准备系统默认输出设备；同一轮译声持续复用，点击停止后释放。准备时可点击停止取消。若默认设备变化或设备中断，工作台显示错误并停止；确认设备后重新开始同传。

运行时查看段落原文、译文、合成、播放和积压状态。可以在界面支持的追赶操作中处理积压；跳过播报不代表原文或译文被删除。先试听小段，避免把播放声音再次送回录音输入。

克隆声音与输出

原生克隆需要已经准备并试音通过的本地模型、参考音与匹配的参考原文。服务克隆使用独立服务配置。选用参考音不会自动保证跨语言音色一致，需测试目标语言。不要一边运行任务一边切换模型或移动文件。

「持续同传（实验）」与「停止同传」固定在面板顶部，向下滚动配置时仍可操作。关闭面板只隐藏面板，运行与播放仍可继续；结束任务请点「停止同传」。录音收尾、合成取消和播放状态需分别确认。

流式语音与延迟

先在「配置引导 → API 配置」保存并试音译声服务的地址、鉴权、模型与音色。工作台在「译声配置」选择「语音服务／API」和已配置提供商，无需再次输入连接。音色、情绪、语速与播放方式可按当前任务调整；服务是否接收整句或增量文本，按界面说明选择。

模型加载与预热归准备时间。连续同传开始前，先等支持预加载的组件准备完成；不支持预加载的组件可能在首句加载，首句需单独看待。准备完成后的语音转语音延迟，仍受讲话分段、识别、翻译、合成首音、排队与设备影响。先测试短讲话，再尝试较长会话。

运行时重点看「源语音起点 → 首音」和「源语音结束 → 首音」。前者包含讲话时长；后者便于观察句尾后的响应。「句尾后识别」包含分段等待，「翻译送达」包含结果送到界面的耗时。「最近译文入队至首音」只统计入队后的合成与排队等环节，不含入队前的识别与翻译。请求总耗时不能代替这些计时。

原生播放优先使用音频驱动的首个有效音频时间戳；Web Audio 与媒体播放使用各自的排程或播放事件，旧原生组件使用软件通知。这些是软件估计，不能当作扬声器实际出声的测量。「时钟校准」只表示时钟对齐误差，设备另有误差。缺少、过期或不匹配的时间戳显示「—」，不补成零；关闭自动播放或播放失败时不产生新测量。

截图展示等待状态，各延迟尚未测量。支持 PCM 流式输出的服务可在响应结束前开始播放；使用 Rust 输出时，新组件会直接交付音频。仅返回完整 WAV 的模型仍需等待完整合成，选择流式播放不会把它变成增量模型。

已完成后台等待的流式音频会直接继续交付。停止可中断等待；旧组件仍保留等待保护。实际响应速度取决于模型和设备，请以运行时计时及试听结果为准。

本次运行统计显示源语音起点和句尾至首音的样本数、p50、p95及最大值。分位数使用最近256个已结束译声任务中的有效计时，完成、失败、停止、跳过和源计时未知为本次累计数量。已有首音但后来失败或停止的计时仍保留，缺计时或未播放不补成零；入队前的识别、翻译失败和前端满载拒绝不在此统计中。停止保留报告，下次运行首段进入语音排程后清空。比较时保留首句、重连和慢段，使用相同模型、语言和设备；这些数值是软件计时。

模型服务的音频到达播放

CosyVoice服务需返回24kHz单声道PCM16。Fish服务需返回带官方44字节WAV头的单声道PCM16音频，采样率为16–96kHz。先用短文本确认服务与参考音能够生成正确声音，再开启「音频到达即播放」。服务端需要提前输出音频，才可能降低首音延迟；只在整段生成后返回音频的服务不会因此提前出声。

每段译文定稿后发送一次，音频到达后即可播放，完整音频在响应结束后保存。Fish流式音频转换为24kHz播放，保存的也是转换后的24kHz音频；关闭此选项可使用原采样率的完整WAV。参考录音原文件不变。发生中断或格式错误时不保存残缺音频；此前已播放的声音无法撤回。此选项不接收增量文本。

  1. 先在配置引导页保存 CosyVoice 或 Fish 的服务根地址与密钥并完成试音。工作台选择「克隆模型服务」和已配置项，再选本次参考录音与参考原文。
  2. 勾选「音频到达即播放」，检查页面提示，再开始连续同传。若需要先检查完整音频，取消勾选即可保留整段生成后播放。
  3. 用自己的设备检查首音延迟、连续播放和音质。需要暂停译声时请停止同传；完整音频可在结果中回听。

FireRed 生成中播放 · 实验

先在配置引导页登记 FireRed 原始根目录并保存，用语音工具完成 FireRed Instruct 短试音。同传「译声配置」选择「本机原生模型」、同一已登记 FireRedTTS3，并将计算设备设为 CPU。当前 Windows 安装包不提供 FireRed 的 CUDA 组件。原始根目录应包含 fireredtts3_instruct、redae、text_tokenizer，无需另开服务或执行 Index 转换。保留完整应用目录及配套运行组件；「准备原生模型」不会补齐缺失的运行组件。检查模型和参考音后，支持的组件可「预置模型与参考音」；等待完成仍须生成短句试听。参考音或原文改动后重新检查、试音，再开始同传。

参考录音须1–10.24秒，建议3–5秒清晰单人讲话，并填写实际录音原文。开启「边生成边播放 · 实验」。工作台自动播放译声。开始持续同传后等待模型、参考音和输出准备完成再讲话；准备可停止取消。

每段完整译文定稿后开始生成，生成中的 PCM 直接交付原生播放，无需等完整 WAV。它不接收任意追加文本；开启后短句提前合成选项隐藏。准备完成不代表运行时已满足实时要求，请观察连续讲话的积压和首音，并用自己的设备试听。持续实时性能、物理设备和完整音质尚未验收。

停止会取消准备或生成并释放输出。关闭面板不会停止同传。若要恢复完整 WAV 路线，先停止再取消生成中播放；若提示组件仅支持完整 WAV，请使用包含新版 FireRed 组件的完整应用目录。

旧截图用于说明控件位置，图中的 CUDA 是较早参数；当前 Windows 安装包使用 FireRed 时请选择 CPU。需要 NVIDIA GPU 时，请选择已支持的 Index-TTS2、Qwen3-TTS 或 VoxCPM2，并先通过组件与设备检查。

原生短句提前合成 · 实验

在「译声配置」选择「本机原生模型」，检查模型和参考录音，再选择「译文短句提前合成 · 实验」。此选项默认关闭，可在停止同传后修改。

源语音分段定稿后，已校验的译文短语可以提前进入合成，并在播放时预生成下一句。中英文等目标语言均使用校验后的短语边界；旧式文本仍等待明确句界。完整原文与回听按原段落保存，识别草稿不会提前说出。

已校验短语按顺序生成，不因译文提前定稿而丢失边界。尚无校验边界的尾段在译文定稿后，可在512字符以内合并生成；更长尾段仍按句界处理。完整译文和回听均保留。

模型仍为每次请求生成完整 WAV。短句可能更早提供可播放音频，也可能增加总合成时间或改变停顿。先用自己的目标语言和参考音试听，检查首音、连续播放与音质；不合适时停止同传并关闭此选项。

停止后，等记录保存完成

点击「停止同传」会立即停止译声播放，录音收尾和记录保存仍可能继续。看到「正在保存同传记录」时，请先等待；播放停止不表示记录已经保存。

若显示「同传记录尚未保存」，先检查保存位置的可用空间和写入权限，再点「重试保存」。未保存期间，软件会暂缓开始新任务、重启软件和恢复其他草稿，先完成本轮保存再继续。

需要离开窗口时，可在退出提示中选择「仅关闭界面 · 后台继续」，让当前软件继续运行。电脑需要保持开机；保存完成前，请不要退出软件、重启或关机。关闭同传面板只会隐藏该面板，正在运行的同传也可能继续。

如果决定放弃尚未保存的部分，请明确选择丢弃本轮草稿并确认。隐藏界面不会丢弃草稿。尚未保存的内容只保留在当前运行的软件中，不要依赖重启后恢复。

CosyVoice 配置一次，再选账户音色

本节 CosyVoice 连接步骤需 Windows r512 或后续安装预览。

  1. 打开配置引导 → API 配置，启用 Alibaba Cloud · CosyVoice。这张卡只配置语音合成。填写自己业务空间和地域对应的完整 wss:// 地址，路径须以 /api-ws/v1/inference 结尾；将地址里的 WorkspaceId 占位符替换为真实值，再填写对应 API Key 和 TTS 模型。完成引导以保存。
  2. 返回同传「译声配置 → 语音服务／API」，明确选择「配置引导 · 阿里云 · CosyVoice · 边译边播」，核对模型和主机名。不会自动选择地域、复制 Aliyun 文本连接或 Qwen Audio 3.1 连接，也不会自动开始同传。
  3. 填写与模型匹配的音色 ID，或按下方步骤选择已有音色。首次选择此来源时音色为空，需要你自己选择。语速范围为 0.5–2；情感写在服务支持的指令中，没有独立情绪参数。手动自定义连接和其他来源的使用草稿继续独立保留。

请从阿里云控制台取得自己的完整地址。地址格式见官方WebSocket 接入指南；模型、音色和指令能力见语音合成模型说明。账户权限、地域、模型和音色需要匹配。

先找已有音色，再按需创建

  1. 在同传点击「克隆 / 设计 / 选择音色」。打开后默认显示「已有音色」，上方显示保存的主机和模型，无需再次输入连接。点击「查询云端音色」才查询账号；打开面板不会自动查询、上传或创建。
  2. 需要新音色时，选择「文字设计」或「参考音克隆」，按页面要求填写，再点击明确的创建按钮。cosyvoice-v2 可查询、使用已有音色和参考音克隆，文字设计按钮不可用并显示原因。cosyvoice-v3.5-plus、cosyvoice-v3.5-flash 需要已经创建的复刻或设计音色，没有预置音色。
  3. 查询后先「检查状态」，再点「生成试听」。完整听完试听后，才能点「用于同传」。返回同传时只更换音色 ID，原来选择的配置引导连接、语气指令、语速和播放方式保留，自定义连接草稿也保留。
模型怎样填写语气与情感提示
cosyvoice-v3.5-plus / v3.5-flash复刻、设计音色支持自然语言指令。
cosyvoice-v3-plus预置音色按音色表指定格式填写；复刻、设计音色不支持指令。
cosyvoice-v3-flash预置音色按指定格式填写；复刻、设计音色支持自然语言指令。
cosyvoice-v2不支持语气指令，保留的旧指令需要先清空。

指令最多 100 个加权字符，汉字计 2，其余字符计 1。例如，50 个汉字已达到上限。音色必须匹配创建时的目标模型；更换模型后请重新核对音色。服务拒绝某种指令时，草稿仍保留，按音色说明修改后再试。

查询、创建和试听会访问选定服务，创建与试听可能计费。点取消或更改保存的连接后，要等待原请求结束，控件才会解锁或换用新连接。若创建结果尚未确认，先用原连接查询音色，勿重复创建；软件不会自动重试创建。连接被停用或移除时，不会改用另一来源。

持续模式可逐步送入译文并接收音频；Mini 仍须先停止本段录音，再等待翻译和完整音频生成后播放。开会前，请用自己的账号、目标语言和输出设备做短试音。

MiniMax 配置一次，再选择译声方式

  1. 进入配置引导 → API 配置，启用 MiniMax 卡，填写服务地址和 API Key，选择 TTS 模型，完成引导后保存。只打开配置卡不会开始同传，也不会创建音色。
  2. 回到同传「译声配置 → 语音服务／API」，明确选择「配置引导 · MiniMax · 整段译文」或「配置引导 · MiniMax · 边译边播」，核对显示的模型和主机名。保存的完整接口地址可能只匹配其中一种方式；另一项不可用时，先到引导页修正地址。
  3. 开始前，先选择或填写账号可用的音色 ID。首次选择 MiniMax 来源时，音色留空，不会替你选默认音色。两种来源共用保存的地址、密钥和模型，分别记住音色、情绪和语速。切换来源会保留另一项的使用参数，旧自定义连接也独立保留。
选择的来源译文怎样交给语音合成
整段译文 · SSE每段译文定稿后，一次提交这一段；音频仍可分批到达、分批播放。
边译边播 · WebSocket Bidi支持逐步送入译文并接收音频。需要你明确选择，不会暗中切换协议。

选择已有音色，或克隆、设计新音色

  1. 在同传音色设置下点击「克隆 / 设计 / 选择音色」，打开 MiniMax 音色面板。面板自动复用当前保存的连接，显示主机和模型，不再要求填写地址、密钥或模型。
  2. 点击「查询音色」才查询账户。需要新音色时，打开「克隆」或「设计」，按要求提供录音或描述，再点击明确的创建按钮。打开页面不会自动查询、上传、创建或合成。
  3. 选中音色，点击「合成试听」，完整听完后再点「用于同传」。这里只更换当前来源的音色，保留原协议、情绪和语速。返回同传，检查所选来源和音色 ID。

创建和试听可能计费，参考录音仅在点击克隆操作时上传。取消后需等待当前操作结束，控件才会解锁。若创建结果尚未确认，请保留音色 ID，用原连接恢复本机记录或按 ID 试听，勿重复提交创建。保存的连接被停用、移除或改变后，先到引导页处理，不会自动退回旧自定义连接。

开会前，用自己的账号、目标语言和输出设备做短文本试音。以下受控示例不代表真实云端音质或延迟已验收。

Mini 也能使用语音 API

「译声配置 → 语音服务／API」的同一选择，同时用于持续按句译声和 Mini。API 路线无需本机 TTS 模型目录或本地参考音，音色使用账号可用的预置音色或已创建的音色 ID。

  1. 先在配置引导页保存语音服务连接与密钥，再用短文本试音。
  2. 返回「译声配置」，选择「语音服务／API」及已保存连接，选择音色，按服务支持情况调整表达参数。不必重复填写地址和密钥。
  3. 打开独立悬浮 Mini，点击开始。看到「录音中」并确认音幅有变化后讲话，再次点击或按 RightAlt 结束本段。
  4. 等待翻译和语音生成。Mini 会先生成完整 WAV 再播放；即使服务支持流式输出，也要先停止本段录音。
  5. 要取消时，点工作台「停止」或「退出 Mini」，等待网络请求与文件保存收尾完成，再录下一段。等状态确认任务已结束后，再更改配置。

可选服务包括 OpenAI PCM、MiniMax SSE／WebSocket、CosyVoice、豆包 SSE／WebSocket、ElevenLabs 和 VibeVoice 服务，具体以已保存连接及账号权限为准。Qwen3.1 TTS Next 请在声音工作台使用，Mini 此处尚未接入该适配。

旧配置若同时启用多条译声来源，请先选择一项。连接、音色或表达参数无效时会明确报错，不会悄悄改用本机模型。译文会发送给所选语音服务；如果识别也选了 API，录音会发送给对应识别服务。Mini 和持续同传均不加入语音水印。实际音质与等待时间请用自己的账号、语言和设备短试。

使用配置引导保存的 OpenAI TTS

  1. 在「配置引导 → API 配置」启用 OpenAI，填写 Base URL 和 API Key，选择 TTS 模型 tts-1、tts-1-hd、gpt-4o-mini-tts 或 gpt-4o-mini-tts-2025-12-15，完成引导以保存。
  2. 回到同传「译声配置 → 语音服务／API」，明确选择名称以「配置引导 · OpenAI TTS」开头、并带模型与主机名的连接。只需填写本次音色 ID，默认是 alloy，不用再次输入地址、密钥和模型。
  3. tts-1 与 tts-1-hd 不支持语气指令，请清空「语气与情感提示」；需要该提示时，换用支持指令的模型。此入口语速固定为 1，没有独立情绪标签。

启用 OpenAI 配置卡不会自动开启同传，仍需在工作台选择连接并手动开始。原有自定义连接独立保留，可按需选择。所选配置引导连接被禁用或移除后，开始操作会明确报错，不会自动切换其他连接或本机模型。

译文会发送到所选服务，云端请求可能计费。请先用短文本试音；真实账号的音质和延迟尚未验收。

从点击开始等待启动确认，到录音、停录收尾、翻译、完整音频生成和播放，Mini 会锁定服务、音色、语言及配置选择。点「停止」后仍需等待结束确认；取消尚未确认或失败时，配置继续锁定，可再点「停止」重试。确认任务已结束后，才能更改配置或录下一段。期间仍可停止录音、生成或播放，也可折叠卡片、查看内容。
